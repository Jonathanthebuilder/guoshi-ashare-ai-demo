# 嘉实财富课堂 Demo 打磨计划（TradingAgents-AShare）

## 目标
给嘉实财富用户上课演示：非专业 Coder 也能用 AI「手搓」A 股投资参考工具。成品要专业、好看、硬核，但必须明确**仅供教学研究，不构成投资建议**。

## 叙事（上课时讲）
1. 打开开源多智能体投研系统（模拟机构：分析师 / 多空辩论 / 风控）
2. 用自然语言：「调研茅台短线」
3. 右侧可视化：14 个 Agent 协作与辩论
4. 产出结构化结论：方向、置信度、目标价、止损、风险（强调参考非建议）
