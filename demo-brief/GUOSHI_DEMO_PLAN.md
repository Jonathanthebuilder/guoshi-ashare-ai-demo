# 嘉实财富 · AI 智能投研工作台演示方案

## 定位
展示专业多智能体架构如何基于真实交易所行情与上市公司公开数据，实现从数据抓取、7 维分析师协作、多空对抗辩论、三方风控裁决到结构化研报生成的全流程自动化。拒绝假壳子与生硬模拟，确保演示全程基于真实行情数据推演。

## 演示主线
1. 打开工作台（实时行情与 14 智能体架构在线）
2. 输入自然语言投研指令：「调研贵州茅台(600519)短线」
3. 观察 14 个 Agent 分布式并发作业，实时抓取行情与财务指标
4. 展开右侧可视化辩论抽屉：多头研究员 vs 空头研究员对抗质辩，风控三方博弈
5. 产出多维度结构化投研报告（方向倾向、置信度、目标价、止损位与量化风险矩阵）

## 核心亮点
1. **真实数据源直连**：直连 A 股交易所行情数据与上市公司公开财报。
2. **多智能体深度协同**：14 位各司其职的 Agent，完整还原顶级投研机构的分工与制衡机制。
3. **沉浸式交互与可视化**：流式发言展现、辩论过程全透明可溯源。
4. **金融级 UI 体验**：深色/浅色专业金融工作台设计，无多余广告干扰。
