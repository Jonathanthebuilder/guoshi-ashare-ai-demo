# 投研工作台 UI 改版实施与验收

实施日期：2026-09-11。依据 `UI_REDESIGN_PROPOSAL.md`，落地前端视觉与连续研究路径；保留现有 API、鉴权、任务执行与中断恢复机制。

## 已落地

- **视觉与导航**：统一“嘉实财富 · 投研工作台”；藏蓝、白底、低饱和状态色；8px 容器、4px 控件、等宽数字；去掉主路径的渐变、光晕、上浮。导航默认 208px，手动折叠为 64px，小屏使用抽屉。主题保留系统/浅色/深色，版本与项目链接移至账户菜单的“关于工作台”。
- **今日工作**：跟踪标的、实际行情快照与日期、最近研究、当前会话任务；分别处理加载、空数据和接口错误。不再显示无依据的“系统正常/行情在线”。
- **标的研究**：标的与研究时点 → 关键研判 → 行情与主要风险；提供研究概览、依据与分歧、完整报告、研究过程四个入口。协作图收进研究过程的展开项，保留阶段状态列表。
- **研究助理**：按需打开，完成报告默认收起；收起时继续挂载流式连接的所有者。小屏有焦点约束、Escape 关闭、背景滚动锁定。切换查询标的时更新未编辑的预填内容，同时保留用户草稿。
- **报告阅读**：默认研究结论，缺失时回退到已有章节；独立目录、760px 正文、Markdown 排版与宽表内部滚动。历史报告支持 `result_data` 回退；终态优先最终原文，导出也优先最终原文。
- **金融语义**：买入/增持、卖出/减持、持有/观望分别保留，修正报告库把 WATCH 显示为持有的行为。未知建议不再默认持有。置信度降为“模型自评”；风控缺失明确提示，讨论中的争议解决状态说明为模型自报。完整风险名称与说明保持可读。
- **登录**：克制双栏品牌与验证码流程，手机品牌区压缩，输入与操作按钮提前。

浏览器验收使用 `/tmp/touyan-ui-qa` 的真实前端组件和隔离 API 样本，页面明确标注“演示测试数据”；没有调用在线模型、发送邮件或修改生产鉴权。实际后端所服务的登录页另行检查。构建输出已更新至 `frontend/dist`。

## 保留的限制

- 后端尚未稳定透传的来源核验、报告版本和风控硬门控，本轮没有补造。UI 只展示已有字段，缺失状态保持可见；这对应方案第三阶段的后端依赖。
- 部分历史研究不保存完整讨论事件，因此讨论记录不能替代原报告。
- 现有 ChatCopilotPanel、Header、Reports 的 hooks lint 报告与改版前保持一致：合计 15 个错误、1 个警告。本次新增的 Sidebar / Dashboard lint 问题已消除，其余改动文件检查通过。
- Vite 仍提示单包大于 500 kB；未在视觉改版中额外引入路由拆包改造。
- 本轮浏览器验证使用确定性样本；不代表已完成真实模型质量评测或真实邮件登录端到端测试。

仓库原有未提交改动继续保留；没有进行 Git 提交或线上部署。
